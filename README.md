# 맑은 물의 에너지 청구서

> 물과 에너지, 대구 공공하수처리시설 데이터를 통해 바라보는 수질과 전력 사용의 관계

## 프로젝트 소개

「맑은 물의 에너지 청구서」는 한국환경공단의 공공하수처리시설 데이터와 2025년 하수도통계 자료를 활용하여 대구 공공하수처리시설의 수질 및 에너지 사용 특성을 분석하는 데이터 시각화 프로젝트입니다.

전력 총량이 큰 시설과 처리량당 전력을 많이 사용하는 시설은 다를 수 있다는 관점에서, 시설의 규모·유입량·처리공법·방류수질 등을 함께 고려하여 에너지 사용 특성을 살펴봅니다.

단순한 전력 사용량 비교를 넘어 전국 유사 시설 비교와 AI 기반 조건부 참고모형, 다양한 조건에 따른 검증을 통해 분석 결과를 탐색합니다.

## 주요 분석 내용

### 01. 수질과 에너지

- 시설별 전력 원단위와 방류 수질 비교
- BOD, T-N, T-P 등 방류 수질 항목 탐색
- 대구 시설과 전국 참고 시설 간 비교
- 전력 원단위와 수질 간 관계 시각화

### 02. 유사 시설 비교

대구 외 전국 공공하수처리시설 중 비교 조건을 만족하는 시설을 선정하여 상대적인 전력 원단위를 비교합니다.

- 동일 처리공법
- 시설용량 조건
- 유입 BOD 조건
- 최소 비교 시설 수 확보

비교 가능한 시설이 충분하지 않은 경우 결과를 제시하지 않으며, 서로 다른 조건의 시설을 무리하게 비교하지 않도록 설계했습니다.

### 03. AI 참고 비교

시설의 용량, 유입량, 수질, 처리공법, 가동연수 및 방류지역 등을 고려한 예측모형을 활용합니다.

- 대구 시설을 학습 데이터에서 제외
- 전국 시설 데이터를 활용한 조건부 예측
- 여러 모형의 실제값 대비 예측값 비교
- 기준 모형과 다른 모형의 결과 탐색

AI 예측 결과는 에너지 낭비나 절감 가능량을 확정하는 값이 아닌 참고 비교값으로 활용합니다.

### 04. 조건별 검증

비교 조건을 변경하면서 분석 결과가 어떻게 달라지는지 확인합니다.

- 시설용량 허용범위 변경
- 유입 BOD 허용범위 변경
- 추가 수질 조건 적용
- 이용률 조건 적용
- 여러 조건 조합에 따른 비교 대상 변화
- 조건부 예측모형 결과 비교

다양한 조건에서 나타나는 결과를 통해 분석의 일관성과 비교 근거를 탐색합니다.

### 05. 시설 나란히 비교

대구 공공하수처리시설을 선택하여 주요 지표를 비교합니다.

- 시설용량
- 이용률
- 연간 전력 사용량
- 전력 원단위
- 방류 BOD
- 에너지 자립률

### 06. 대구 시설 현황

대구 공공하수처리시설 전체 및 시설용량 500 이상인 시설을 대상으로 주요 지표를 확인합니다.

- 연간 전력 총량순
- 전력 원단위순
- 에너지 자립률순
- 시설별 주요 운영 및 수질 정보

## 주요 지표

| 지표 | 설명 |
|---|---|
| 연간 전력 사용량 | 시설의 연간 전력 소비량 |
| 전력 원단위 | 처리량 대비 전력 사용량 |
| 시설용량 | 하수처리시설의 계획 처리 규모 |
| 이용률 | 일평균 유입량 대비 시설용량 비율 |
| 방류 BOD | 방류수의 생화학적 산소요구량 |
| 방류 T-N | 방류수의 총질소 농도 |
| 방류 T-P | 방류수의 총인 농도 |
| 에너지 자립률 | 시설별 에너지 자립 수준 |

### 전력 원단위 계산

전력 원단위는 연간 전력 사용량을 연간 유입하수량으로 나누어 계산합니다.

전력 원단위 = 연간 전력 사용량(kWh) / (일평균 유입하수량(m³/day) × 365일)

단위: kWh/m³

## 분석 시 유의사항

- 전력 총량과 전력 원단위는 서로 다른 지표입니다.
- 전력 원단위가 높다는 사실만으로 에너지 낭비를 판단할 수 없습니다.
- AI 예측값과 실제값의 차이는 확정적인 절감 가능량을 의미하지 않습니다.
- 방류 수질은 법적 기준 준수 여부를 판정하기 위한 목적이 아닙니다.
- 시설별 계량 범위, 운영 조건, 설비 구성 및 개조 이력은 추가 확인이 필요할 수 있습니다.
- 본 분석은 연도별 추세, 운영 적정성, 확정 절감량 및 전 생애주기 탄소배출량을 평가하지 않습니다.

## 프로젝트 목적

공공하수처리시설의 수질과 에너지 사용을 함께 분석함으로써, 시설별 특성과 비교 조건에 따라 달라지는 에너지 사용 특성을 데이터 기반으로 탐색하고자 합니다.

공공데이터와 AI 분석을 활용하되, 분석 결과뿐 아니라 비교의 근거와 한계까지 함께 제시하는 것을 목표로 합니다.
