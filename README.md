# 맑은 물의 에너지 청구서

> 대구 공공하수처리시설의 수질과 에너지 사용을 함께 읽는 공식자료 기반 분석 대시보드

## 프로젝트 소개

공공하수처리시설의 전력 사용량은 처리시설의 규모뿐 아니라 유입수의 특성, 처리공법, 운영 조건 등 다양한 요인의 영향을 받습니다. 따라서 전력 총량이 높은 시설과 처리량 대비 전력을 많이 사용하는 시설을 구분하여 살펴볼 필요가 있습니다.

**「맑은 물의 에너지 청구서」**는 대구 공공하수처리시설의 수질 및 에너지 사용 데이터를 분석하고, 전국 유사 시설과의 비교 및 조건부 예측 모형을 활용해 시설별 에너지 사용 특성을 탐색하는 인터랙티브 대시보드입니다.

단순한 에너지 사용량 순위에 그치지 않고, 시설의 규모와 처리 조건을 함께 고려하여 비교 결과가 어떤 조건에서 나타나는지 확인하는 데 목적이 있습니다.

## 주요 기능

### 1. 수질과 에너지 사용량 분석
- 대구 공공하수처리시설별 전력 사용량 및 전력 원단위 확인
- 방류수 BOD, T-N, T-P 농도 확인
- 시설용량, 유입량, 이용률 등 시설 운영 관련 정보 제공
- 전력 원단위와 방류 수질의 관계를 산점도로 탐색

### 2. 유사 시설 비교
- 대구 외 전국 공공하수처리시설을 대상으로 비교
- 동일 처리공법 및 시설 규모, 유입 BOD 조건을 고려한 비교 대상 선정
- 비교 가능한 상대 시설이 충분하지 않은 경우 결과를 무리하게 산출하지 않음
- 유사 시설의 전력 원단위와 방류 수질 비교

### 3. AI 기반 조건부 참고 비교
- 시설의 규모, 유입량, 수질, 처리공법, 가동연수 및 방류지역 등을 고려한 예측 모형
- 여러 모형의 결과를 비교하여 실제 기록과 예측값 사이의 차이 탐색
- AI 예측값을 절대적인 효율 기준이 아닌 참고 비교값으로 제공

### 4. 조건별 검증 및 민감도 분석
- 시설용량 및 유입 BOD 허용범위에 따른 비교 결과 확인
- 추가 조건을 적용했을 때 비교 대상이 어떻게 달라지는지 탐색
- 여러 비교 설정과 모형에서 나타나는 결과의 일관성 확인
- 비교 대상이 부족한 조건은 분석 결과 해석에 반영

### 5. 시설별 상세 비교
- 대구 공공하수처리시설 간 주요 지표 비교
- 시설별 전력 사용량, 전력 원단위, 처리 규모, 수질 및 자립률 확인
- 대시보드에서 시설을 선택하여 비교 정보 변경

### 6. 분석자료 다운로드
- 대구 시설 분석 결과를 CSV 파일로 다운로드
- 시설별 주요 지표 및 비교 결과 확인 가능

## 분석 지표

| 지표 | 설명 |
|---|---|
| 연간 전력 사용량 | 시설의 기록된 연간 전력 사용량 |
| 전력 원단위 | 일평균 유입하수량과 365일을 기준으로 환산한 처리량 대비 전력 사용량 |
| 시설용량 | 공공하수처리시설의 처리 용량 |
| 유입하수량 | 시설로 유입되는 하수량 |
| 이용률 | 일평균 유입하수량 / 시설용량 |
| 방류 BOD | 처리 후 방류수의 BOD 농도 |
| 방류 T-N | 처리 후 방류수의 총질소 농도 |
| 방류 T-P | 처리 후 방류수의 총인 농도 |
| 에너지 자립률 | 원자료에 기록된 시설별 에너지 자립률 |

### 전력 원단위 계산

전력 원단위는 시설별 연간 전력 사용량을 연간 처리량으로 나누어 산출합니다.

\[
\text{전력 원단위}
=
\frac{\text{연간 전력 사용량 (kWh)}}
{\text{일평균 유입하수량 (m³/day)} \times 365}
\]

단위는 **kWh/m³**이며, 시설별 처리량을 고려한 전력 사용 수준을 비교하기 위한 지표입니다.

## 분석 방법

### 유사 시설 비교 기준

유사 시설 비교 시 다음 조건을 적용합니다.

- 대구 외 시설
- 시설용량 500 이상
- 동일 처리공법명
- 시설용량 허용범위: 비교 시설의 1/3~3배
- 유입 BOD 허용범위: 비교 시설의 1/2~2배
- 최소 5개 비교 시설 확보 시 중앙값 비교

조건을 충족하는 비교 시설이 5개 미만인 경우에는 비교 결과를 보류합니다. 이는 서로 다른 공법이나 조건의 시설을 무리하게 비교하는 것을 방지하기 위한 기준입니다.

### AI 참고모형

- 대구 지역 시설은 학습에서 제외
- 전국 대구 외 시설 데이터를 활용
- 시도 단위 GroupKFold 5분할 검증
- 수치형 변수 및 처리공법, 가동연수, 방류지역 등의 변수 활용
- Ridge Regression, Random Forest, Boosting 등 모형 비교
- 기준 모형은 사전에 설정한 Ridge Regression (α=20)

AI 모형은 시설별 기록을 바탕으로 조건부 참고값을 제공하며, 실제 운영 효율이나 에너지 절감 가능량을 직접 산출하는 모델은 아닙니다.

### 조건별 검증

- 시설용량 허용배수: 1.5, 2, 3, 5
- 유입 BOD 허용배수: 1.5, 2, 3
- 추가 비교 조건 조합을 활용한 분석
- 시설별 48개 비교 설정 검토
- 여러 AI 모형 및 학습 지역 제외 설정을 통한 결과 검증

조건별 결과는 서로 중첩된 비교 설정이므로 독립적인 반복 실험이나 확률로 해석하지 않습니다.

## 해석 시 유의사항

본 대시보드는 공개 데이터를 활용한 탐색적 분석 도구이며, 다음 사항을 유의해야 합니다.

- 전력 총량과 전력 원단위는 서로 다른 의미를 갖습니다.
- 전력 원단위가 높다는 사실만으로 에너지 낭비를 확정할 수 없습니다.
- AI 예측값과 실제 기록의 차이를 절감 가능량으로 해석하지 않습니다.
- 방류 수질은 법적 기준 준수 여부를 판정하기 위한 목적이 아닙니다.
- 동일한 처리공법명이라도 세부 설비 및 운전 조건이 동일하다는 보장은 없습니다.
- 시설별 계량 범위, 가동 기간, 개조 및 시운전 이력 등은 추가 확인이 필요합니다.
- 본 분석은 연도별 추세, 운영 적정성, 확정적인 에너지 절감량 및 전 과정 탄소배출량을 평가하지 않습니다.
